# Prompt para agente de animación de pseudocódigo

Objetivo:
- Mostrar de manera visual y paso a paso cómo se ejecuta un pseudocódigo.
- Resaltar el flujo lógico, el estado de las variables y las decisiones tomadas.

Comportamiento de la animación:
1. **Inicio**
   - Resaltar la primera línea de pseudocódigo.
   - Mostrar panel de variables vacío o inicializado.

2. **Ejecución paso a paso**
   - Avanzar línea por línea.
   - Cada vez que se evalúe una condición (ej. SI, MIENTRAS), mostrar visualmente:
     - Condición evaluada (verdadero/falso).
     - Flecha hacia el bloque que se ejecuta.
   - Actualizar valores de variables en un panel lateral.

3. **Bucles**
   - Repetir la animación de la condición hasta que sea falsa.
   - Mostrar contador de iteraciones para mayor claridad.

4. **Condicionales**
   - Si la condición es verdadera, resaltar el bloque correspondiente.
   - Si es falsa, mostrar el salto al bloque alternativo.

5. **Finalización**
   - Indicar claramente cuándo el programa termina.
   - Mostrar estado final de todas las variables.

Estilo visual:
- Resaltar la línea activa con color.
- Animar transiciones con flechas o resaltados.
- Panel lateral siempre visible con variables y sus valores.
- Opcional: diagrama de flujo dinámico que se va iluminando según el recorrido.

Interactividad:
- Botones: “Ejecutar todo”, “Ejecutar siguiente”, “Reiniciar”.
- Posibilidad de pausar y retroceder pasos.

Meta:
- La animación debe ser clara, educativa y fácil de seguir.
- Evitar sobrecarga visual: usar colores y movimientos simples.
